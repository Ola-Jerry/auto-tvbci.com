TVB CI AUTO WEBSITE

Files:
- index.html: website structure
- style.css: responsive black and gold design
- script.js: mobile menu and photo gallery
- assets/: supplied vehicle photos

Local preview:
Open index.html in a browser.

Deployment:
Upload the folder to Netlify, or connect it to a GitHub repository.
Then add your domain/subdomain in Netlify Domain management.

Before publishing:
- Confirm the vehicle's year, price, mileage, engine and legal documents.
- Replace the WhatsApp number if needed.
- Confirm the exact domain and DNS records before changing anything.
